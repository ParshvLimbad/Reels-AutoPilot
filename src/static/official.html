Dashboard

Connecting switches this account away from password login. Tokens are write-only and stored on this Pi.

Use existing scraped reels

Uses downloaded videos and the cover configured in your dashboard. The Pi creates temporary media links automatically. Missing videos must be downloaded before posting.

Import an Instagram reel

Paste a reel link. The worker downloads it on the next scrape cycle, uses your saved caption and cover, and publishes from the existing queue. Already queued or delivered reels are not added again.

Queue a direct media URL (advanced)

Use direct public HTTPS links to the video and cover. Instagram profile links and local Pi paths will not work. This queue is separate from the existing scraper queue.
